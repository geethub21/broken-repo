# Assignment 1 — Fix the Broken Repository

## Description

This repository contains a C++ program that simulates a simple sensor data logger.

The program generates five random sensor readings and stores them in a text file. It also creates several additional files and directories during execution, including a log file, a temporary file, a fake executable artifact, and a cache file.

The purpose of this assignment is to identify and manage these generated files correctly using Git and GitHub practices without modifying the provided C++ source code.

## Output Directory

The valid output of the program is the sensor data generated by the program.

The valid output file is:

src/output/sensor_data.txt

This file contains the sensor data log with five randomly generated sensor readings.

Other files generated during program execution, such as 
run.log, temp.tmp, program.exe, and cache/cache.data, are not considered valid repository output and should not be included in the final repository.
